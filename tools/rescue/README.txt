这个目录里的脚本是「应急用」的，平时不用打开。

日常只有一个入口：仓库根目录的 dsh-ui.cmd（图形页）。
第一次插盘或换盘重建，用根目录的 build.cmd。

什么时候才需要来这里
--------------------
- 图形页打不开 / 本地服务起不来 —— 用 dsh-doctor.cmd 先体检：
  Node 在不在、槽位里有没有东西、端口被谁占着、密钥库是否可读、有没有残留进程。
- 想绕过我们的本地服务、直接看 dsh 自己的界面 —— dsh.cmd。
- 不想开浏览器，要在命令行里跑一句话 —— dsh-cli.cmd（--version / headless "任务"）。
- 图形页彻底用不了，又急着改密钥、切槽位、看站点 —— dsh-config.cmd（终端菜单）。

这些脚本也带拔盘守护
--------------------
用 dsh.cmd 起 dsh 时，启动器会在盘上留一个哨兵文件（runtime\.drive-id）并每几秒读一次；
盘被拔走就杀掉 dsh 自己退出（退出码 3，表示「盘没了」，不是崩溃）。别手删那个哨兵文件。

四个脚本各是干什么的
--------------------
dsh.cmd          起 dsh 自己的 Web UI：解锁密钥 → 选活动槽 → 校验站点覆盖层 → 起服务并开浏览器。
dsh-cli.cmd      命令行 / headless 用法，参数原样转给启动器。
dsh-config.cmd   终端维护台（菜单）：自检 / 升级 / 切槽 / 备份 / 密钥 / 站点配置 / 打开图形页。
dsh-doctor.cmd   一键体检，只读，不改任何东西（除了它自己的输出）。

改这几个脚本时注意
------------------
- 它们不在根目录：仓库根目录是「本文件所在目录的上一级的上一级」（脚本里用 %~dp0..\.. 算出来）。
  如果把它们再挪位置，这一行必须跟着改，否则找不到 runtime\ 和 tools\。
- 必须保持纯 ASCII。.cmd 里的中文在 cmd 窗口里会显示成乱码，所以英文注释 + tools\msg\ 下的中文文案文件是刻意的设计。
- 用 %~dp0 推导一切路径，不要写死盘符 —— 这个包要能在 F: / G: / X: 任何地方跑。
